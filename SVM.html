The core idea to keep in your head:

The kernel trick: the SVM dual only ever uses dot products between data points. Replace each dot product xᵢᵀxⱼ with a kernel K(xᵢ, xⱼ) and you get a classifier that is linear in a huge hidden feature space but curved in the original space, without ever building those features.

C · Why the shortcut matters: cost of explicit lifting

A degree-p polynomial lift of d input features has C(d+p, p) coordinates. The kernel (xᵀz+1)^p costs about d multiplications regardless.

For the RBF kernel the lifted space is infinite-dimensional, so explicit lifting is impossible — only the kernel makes it usable.

D · The RBF kernel as a similarity score

K(x, x') = exp(−‖x − x'‖² / 2σ²) equals 1 when the points coincide and fades toward 0 with distance. σ sets how far a support vector's influence reaches.

Flashcards

Big picture

Many lines can separate two classes. The SVM picks the one with the maximum margin: the widest "street" between the classes. A wide margin makes the classifier less sensitive to small perturbations of the data, so it tends to generalise better.

  1. Hard margin (perfectly separable data): minimise ½‖w‖² subject to ỹₙ(wᵀxₙ+w₀) ≥ 1. A short w means a wide margin.
  2. Dual form: one multiplier αₙ per point. Result: w = Σ αₙỹₙxₙ, only support vectors (α>0) matter, and data appears only inside dot products.
  3. Soft margin: slack ξₙ ≥ 0 lets points violate the margin at cost C each. The dual only changes to 0 ≤ αₙ ≤ C.
  4. Kernel trick: swap xᵢᵀxⱼ for K(xᵢ,xⱼ) to get nonlinear boundaries, or classify strings and graphs.

The kernel trick at three levels

1 · Intuition

Red marbles ring a clump of blue ones on a table; no stick separates them. Flick the table so the centre marbles fly higher, and a flat sheet slid between the heights separates them. A kernel gives you the benefit of that lift while only computing a cheap similarity score between pairs of points in the original space.

2 · Concrete example

With φ(x) = (x₁², √2x₁x₂, x₂²), φ(x)ᵀφ(z) = (xᵀz)². For x=(1,2), z=(3,1): both routes give 25, but the shortcut never builds the lifted vectors. For d=100 and degree 5 the lifted space has about 96 million coordinates, while the kernel costs about 100 multiplications.

3 · Technical

A Mercer (positive-definite) kernel has a symmetric positive semi-definite Gram matrix for any finite point set, so a feature map φ into a Hilbert space exists with K(x,x') = ⟨φ(x),φ(x')⟩ (possibly infinite-dimensional). Because the dual touches data only via dot products, prediction becomes f(x) = Σ_{n∈S} αₙỹₙK(xₙ,x) + w₀. The cost scales with the number of data points (an N×N Gram matrix), not the feature dimension.

Answers to the self-check questions

  1. Why does the trick need dot products? The dual objective and prediction rule contain the data only as pairs xᵢᵀxⱼ. Swapping that pairing for K changes nothing else. In the primal, the unknown w lives in feature space, which may be infinite-dimensional.
  2. Why is (xᵀz)² cheaper? It scales with the input dimension d; the explicit lift scales with the (huge or infinite) feature dimension.
  3. RBF overfitting? Increase σ (smoother, longer-reaching influence) and decrease C (tolerate more training errors). Tune both together with cross-validation, on log scales.
  4. Why must K be positive definite? So that K really is an inner product somewhere (Mercer), and so the dual stays a convex problem with a single global optimum.

Key facts and tips

  • Support vectors: points with αₙ>0 (on or inside the margin, or misclassified). Delete every other point and the solution is unchanged.
  • C: large = narrow margin, tight fit, overfitting risk (C=∞ is hard margin). Small = wide margin, more tolerance, underfitting risk.
  • Σξₙ is an upper bound on the number of misclassified training points.
  • ν-SVM: ν replaces C; it upper-bounds the fraction of margin errors and lower-bounds the fraction of support vectors.
  • Scale features first (Fig. 17.14): the margin treats all dimensions equally.
  • Training cost: generic QP is O(N³); SMO is roughly O(N) to O(N²).
  • SVM outputs are scores, not probabilities (Fig. 17.15). Use calibration or a probabilistic model if you need probabilities.
  • Common kernels: linear, polynomial (xᵀx'+c)^d, RBF exp(−‖x−x'‖²/2σ²). Sums, products and positive scalings of valid kernels are valid. The sigmoid kernel is not always positive definite.
  • Beyond SVMs: any algorithm that uses only dot products can be kernelized (kernel PCA, kernel ridge regression, Gaussian processes).

Applications

  • Text: spam filtering, sentiment analysis, topic labelling (high-dimensional, sparse data).
  • Images: handwritten digits and object classification with kernels.
  • Bioinformatics: protein and gene classification with string kernels (for example, a spectrum kernel counting shared length-k substrings); cancer classification from gene expression.
  • Medicine: diagnosis from measured features, especially with small datasets.
  • Structured data: molecules and networks via graph kernels. You only need a similarity function, not a feature vector.
  • Regression: the same framework extends to support vector regression.

Limitations: the O(N²) Gram matrix on very large datasets, tuning kernel hyperparameters, no probabilities out of the box, and no automatic way to pick the right kernel.
