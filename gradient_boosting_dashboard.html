Final Exam Study Guide: Tree Ensembles

1. The Principle of Gradient Boosting

Instead of fitting one giant model, gradient boosting builds an ensemble of weak learners sequentially. It frames machine learning as gradient descent in function space.

At step $m$, the algorithm computes the gradient of the loss function (the pseudo-residuals, $g_{im}$). A weak learner $F_m(x)$ is trained to approximate these residuals. The ensemble is then updated:

$$f_m(x) = f_{m-1}(x) + \nu F_m(x)$$

Where $\nu$ is the shrinkage factor (learning rate).

2. XGBoost (Extreme Gradient Boosting)

XGBoost is a highly optimized, scalable version of gradient boosting. It introduces two major mathematical improvements over standard implementations:

  • Second-Order Approximation: It utilizes both the gradient and the Hessian ($h_{im}$, the second derivative) of the loss function for faster, more accurate convergence via Taylor expansion.
  • Explicit Regularization: It penalizes complex trees directly in the objective function to prevent overfitting:
$$\Omega(f) = \gamma J + \frac{1}{2}\lambda \sum_{j=1}^{J} w_j^2$$

Where $J$ is the number of leaves and $w_j$ are the leaf weights.

3. Interpreting Tree Ensembles

Feature Importance

Answers "which features matter most?" It is calculated by summing the reduction in loss (the gain, $G_j$) every time a specific feature is used to split a node across all trees in the ensemble.

$$R_k(T) = \sum_{j=1}^{J-1} G_j I(v_j = k)$$

Partial Dependency Plots

Answers "how does a feature impact the output?" It isolates feature $k$ by plotting its values against the average prediction of the model, marginalizing out all other features $x_{-k}$.

$$\bar{f}_k(x_k) = \frac{1}{N} \sum_{n=1}^N f(x_{n,-k}, x_k)$$
