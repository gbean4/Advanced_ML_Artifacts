Understanding CART

Classification and Regression Trees: Mathematical Foundations & Interactive Simulator

Conversation Summary

Here is a recap of the key mathematical and conceptual elements of CART discussed previously:

  • 1. Model Definition: A decision tree models a function \( f(x) \) as the sum of constant predictions \( c_m \) across partitioned regions \( R_m \):
    \[ f(x) = \sum_{m=1}^{M} c_m I(x \in R_m) \]
  • 2. Recursive Binary Splitting: Trees are built using a top-down, greedy approach. At each node, the algorithm searches for the feature \( j \) and threshold \( t \) that minimizes the total cost (impurity).
  • 3. Regularization: To prevent over-fitting (where every leaf has 1 sample), CART uses Cost-Complexity Pruning, minimizing \( R_\alpha(T) = R(T) + \alpha |T| \), where \( \alpha \) penalizes tree size \( |T| \).
  • 4. Missing Features: CART handles missing data natively via surrogate splits, finding alternative features that mimic the primary split's distribution as closely as possible.
  • 5. High Variance (The Iris Example): CART models are unstable. As seen in the Iris dataset textbook figure, removing a single data point can drastically alter the chosen splits and decision boundaries.
  • 6. Ensembles: Algorithms like Random Forests average many high-variance trees to create a stable model, smoothing out CART's strict axis-aligned boundaries into flexible contours.
