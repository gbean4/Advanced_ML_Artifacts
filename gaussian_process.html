How to Use

  • Click anywhere on the plot to add an observation point (a "training data" point).
  • Observe how the solid blue line (posterior mean) updates to fit the data.
  • The shaded blue region represents predictive uncertainty ($\pm 2$ standard deviations). Notice it pinches near data points and expands far away.
  • Set Noise Variance to `0` to force the curve to pass exactly through every point (Interpolation). Increase it to allow the curve to smooth over noisy points.
  • Adjust Length Scale to change the model's assumption of smoothness. Smaller values = rigid/rapidly changing. Larger = smooth/slowly changing.

Gaussian Process Key Points

1. Non-Parametric Bayesian Regression

Instead of assuming a fixed function form (like $y = mx+b$), GPs define a probability distribution over all possible functions. We start with a prior, and update to a posterior upon seeing data.

2. The Covariance Function (Kernel)

The heart of a GP. This artifact uses the Squared Exponential (RBF) Kernel:
k(x,x') = σ_f² * exp(-(x-x')² / (2l²)) It dictates that inputs $x$ and $x'$ which are close together will have highly correlated outputs.

3. Noise-Free vs Noisy Observations

When observations are assumed to be perfect (Noise Variance = 0), the GP acts as an exact interpolator. With noise, the model assumes $y = f(x) + \epsilon$ where $\epsilon \sim \mathcal{N}(0, \sigma_n^2)$, smoothing the curve instead of strictly passing through every point.

4. Computational Complexity

To compute the posterior, we must invert the $N \times N$ covariance matrix $\mathbf{K}_{XX}$. Matrix inversion has a complexity of $\mathcal{O}(N^3)$, making standard GPs slow for large datasets ($>10,000$ points).
